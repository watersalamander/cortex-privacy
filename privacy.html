Cortex: Privacy Policy

Last updated: 13 October 2026

Cortex is an internal knowledge assistant. It answers questions from a team's own documents and shows each person only what they are already allowed to see in the source system. This page explains what Cortex does with data from Google accounts that are connected to it.

What Cortex reads from Google

When an account is connected, Cortex asks for read-only access to Google Drive (drive.readonly). It reads only the folders an administrator has configured, and their subfolders. In those folders it reads file names, file contents and each file's sharing list. It cannot change, delete or share anything in Drive, and it does not read files outside the configured folders.

How the data is used

File contents are indexed so that Cortex can find passages that answer a question. Sharing lists are used to decide who may see each document: a person gets an answer only from documents shared with them in Drive. The data is not used for advertising, is not sold, and is not used to train machine-learning models.

Where the data is stored

The index, the sharing information and the account's refresh token are stored on the server that runs Cortex. The search index is built on that server.

Who the data is shared with

To write an answer, Cortex sends the passages the asker is allowed to see to a hosted language-model service (Tencent Cloud Agent Development Platform). Documents the asker may not see are never sent to it. Data is not shared with anyone else.

Google API Services User Data Policy

Cortex's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

An account holder can remove Cortex's access at any time at myaccount.google.com/permissions. To have indexed data from an account deleted, write to the contact below.
